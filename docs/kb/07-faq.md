# Частые вопросы (FAQ)

**Нужно ли знать португальский язык?**
Для подачи на ВНЖ — нет, не обязательно. Для получения гражданства —
португальский нужен.

**Сколько занимает оформление ВНЖ?**
1–2 месяца. Благодаря опыту команды результат одобрения гарантирован.

**Какие документы нужны?**
Базовый набор: свидетельство о рождении с апостилем, справка об отсутствии
судимости с апостилем, свидетельство о браке с апостилем (если есть).
Помогаем, даже если апостилей нет; минимальный вариант по рождению
ребёнка — один паспорт. Недостающие документы можно истребовать в
консульстве РФ в Бразилии.

**Можно ли начать оформление до приезда в Бразилию?**
Да: предварительная подготовка идёт по электронным сканам, подача возможна
и через консульства других стран онлайн. Оригиналы подаются лично уже в
Бразилии.

**Можно ли выезжать из Бразилии с ВНЖ?**
Да, с ВНЖ можно свободно покидать страну и возвращаться без ограничений.

**Как проходит работа с вами?**
Бесплатная первая консультация → договор (или публичная оферта) → весь
процесс в приватном чате: сбор и переводы документов, запись в органы,
сопровождение переводчиком, отслеживание статуса до результата.

**Ребёнок родился в Бразилии — он сразу гражданин?**
Да, гражданство Бразилии по рождению на территории страны закреплено
Конституцией. Родители при этом получают постоянный ВНЖ.

**Чем сопровождение родов отличается от юридического пакета?**
Сопровождение родов ($2000) — это доула, клиника, роды и бытовая
поддержка. Юридический пакет «ВНЖ по рождению ребёнка» ($500/чел.) — это
документы. Обычно семьи берут комплекс: роды + документы всей семье;
состав и итоговая цена фиксируются договором.
